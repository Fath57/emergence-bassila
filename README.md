# Emergence Bassila

Application Laravel moderne avec une landing page attrayante utilisant des couleurs plates.

## Caractéristiques

- **Design Moderne**: Landing page avec des couleurs plates et des animations fluides
- **Responsive**: Compatible avec tous les appareils (mobile, tablette, desktop)
- **Performance**: Optimisé pour la vitesse et l'expérience utilisateur
- **Laravel 10**: Framework PHP moderne et robuste

## Installation

1. Cloner le repository
```bash
git clone <repository-url>
cd emergence-bassila
```

2. Installer les dépendances
```bash
composer install
```

3. Configurer l'environnement
```bash
cp .env.example .env
php artisan key:generate
```

4. Lancer le serveur de développement
```bash
php artisan serve
```

Visitez `http://localhost:8000` pour voir l'application.

## Structure

- `app/Http/Controllers/` - Contrôleurs de l'application
- `resources/views/` - Vues Blade
- `public/css/` - Fichiers CSS
- `routes/web.php` - Routes de l'application

## Technologies

- Laravel 10
